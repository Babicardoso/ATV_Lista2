# 📘 Exercícios de Lógica de Programação

Este repositório contém a resolução de exercícios básicos de lógica de programação utilizando **fluxogramas** e **pseudocódigos**.

## 📌 Conteúdo Desenvolvido

Foram elaborados fluxogramas e pseudocódigos para os seguintes problemas:

### ➕ Soma de Dois Números
- Entrada de dois valores numéricos
- Processamento da soma
- Exibição do resultado

### 📊 Média de Três Notas
- Entrada de três notas
- Cálculo da média 
- Exibição da média final

### 📐 Área do Trapézio
- Entrada das bases maior e menor, e altura
- Aplicação da fórmula da área
- Exibição do resultado

### ⚖️ Cálculo do IMC
- Entrada de peso e altura
- Cálculo do Índice de Massa Corporal (IMC)
- Exibição do resultado

### 🌡️ Conversão de Celsius para Fahrenheit
- Entrada de temperatura em graus Celsius (°C)
- Conversão para Fahrenheit (°F)
- Exibição do resultado

### 🏡 Área de um Terreno
- Entrada das dimensões do terreno
- Cálculo da área total
- Exibição do resultado

## 🎯 Objetivo

O objetivo destes exercícios é praticar:
- Lógica de programação
- Construção de algoritmos
- Representação de soluções com fluxogramas
- Escrita de pseudocódigos

## 🚀 Tecnologias Utilizadas

- Lógica de Programação
- Fluxogramas
- Pseudocódigo

## 📚 Observação

Este material é voltado para iniciantes que estão aprendendo os conceitos básicos de algoritmos e desenvolvimento de soluções computacionais.
